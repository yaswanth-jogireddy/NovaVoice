# Loan application stages

A loan application moves through these stages: submitted, document verification, credit assessment, approved, and disbursed. Document verification usually takes 2 to 3 working days once all documents are received; credit assessment usually takes 3 to 5 working days.

An application is approved only when the sanction letter is issued. The first EMI date is set when the loan is disbursed, normally in the month after disbursal. If a document is missing, the bank contacts you on your registered mobile and email.
